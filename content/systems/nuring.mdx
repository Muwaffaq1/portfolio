## Why it was needed

Nūring turns grip into data: effort, recovery and accumulated load, starting with baseball. The same numbers are read by an athlete mid-session, a coach deciding who needs attention, and a parent checking on their child. The system had to make dense data calm to read, and make sure a colour never means two different things.

## How it's structured

Five variable collections: **Primitives, Color, Space, Radius and Motion.** Components only use semantic tokens, never raw values.

Three typefaces, each with one job: **Archivo Black** for display and hero numbers, **Host Grotesk** for interface text, **JetBrains Mono** for tabular data. Space doubles at every step from 2 to 128, and radius nests: an inner element's radius is the outer radius minus the padding between them.

## One scale for every score

## Documentation and governance

- **Rules written into the file:** depth comes from stacking surface tones; shadows are only for things that float (popovers, modals, the expanded player card).
- **Names that travel:** each Figma token shows its CSS name beside it, such as `bg/surface` → `--color-bg-surface`.
- **Copy stored in natural case:** the Label, Action and Code styles set capitals, so text isn't retyped when a style changes.
- **Status is reserved:** green, amber and red are never used for decoration, so they always mean something.
